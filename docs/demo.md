# Day Zero Demo

Target runtime: under 3 minutes.

1. Start with the connected repo, calendar and Slack channel.
2. Show a red CI build from overnight.
3. Show the trace: three bounded iterations, diagnosis, rerun and green build.
4. Show the three-sentence morning briefing.
5. Show the authentication PR being escalated because of category policy, even if model confidence is high.
6. Approve the drafted standup/status action with one tap.
7. Close by showing the four-layer architecture and evaluation suite.

## Pre-seeded demo state

- Flaky integration test that can be forced to fail.
- 2–3 calendar events with a real conflict.
- Routine Slack status check.
- PR touching an authentication path so escalation is guaranteed.
